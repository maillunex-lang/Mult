# Производство EP-001

## Концепция

- Сериал: **Бип и его открытия**
- Серия: **Бип и красный мячик**
- Аудитория: 1–3 года
- Стиль: Soft Toy 3D Animation
- Движок: Godot 4.4 (gl_compatibility для software/Mesa)

## Пайплайн

1. **Ассеты** — CC0 модели (Quaternius, Kenney) + Blender-адаптация.
2. **Сцена** — `SceneBuilder.gd` собирает комнату, свет, реквизит, Бипа.
3. **Таймлайн** — `EpisodeDirector.gd`, 18 кадров / 180 с, детерминированно по номеру кадра Movie Maker.
4. **Озвучка** — Edge TTS / eSpeak-NG → `audio/narrator`, `audio/beep` → master WAV.
5. **Рендер** — `scripts/build_episode.sh` (Movie Maker + FFmpeg).

## Персонаж Бип

- База: Quaternius Animated Robot (CC0)
- Рост: ~65 см (`scale = 0.13`)
- Цвет: #75D4E8, матовый пластик
- Жёлтая антенна
- Анимации: Idle, Walking, Wave, Yes, No, Punch (толчок) и др.

## Комната

- ~6×5 м, кремовые стены, светлый пол, мятный коврик
- Большое окно с мягким дневным светом
- Жёлтое кресло, стеллаж Kenney, зелёная корзина, красный мяч Ø28 см
