# EP-002 — «Бип и цветные шарики»

## Для кого

Дети **до 2 лет**. Спокойный темп, крупные формы, яркие цвета, повтор.

## Формат

- 2D Soft Toy анимация
- 1920×1080, 30 FPS, ~100 секунд
- **Без озвучки**
- Русские субтитры крупно внизу кадра (+ файл `.srt`)
- Мягкая оригинальная музыка

## Сюжет

1. **Утро** — солнышко, облака, появляется Бип. Субтитр: «Бип и цветные шарики»
2. **Привет** — Бип машет рукой. «Привет!»
3. **Красный** — припрыгивает красный шарик. «Красный шарик»
4. **Жёлтый** — жёлтый шарик. «Жёлтый шарик»
5. **Синий** — синий шарик. «Синий шарик»
6. **Зелёный** — зелёный шарик. «Зелёный шарик»
7. **Вместе** — все шарики прыгают, лёгкий счёт. «Раз… два… три… четыре!»
8. **Пока** — Бип машет. «Пока-пока!»

## Педагогическая цель

Знакомство с **четырьмя основными цветами** через один понятный объект (шарик), с повтором и спокойной музыкой.
