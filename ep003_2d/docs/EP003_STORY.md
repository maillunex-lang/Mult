# EP-003 — «Бип считает до десяти»

## Для кого

Малыши, знакомство с цифрами **1–10**. Музыкальный формат.

## Формат

- 2D стильный Soft Toy / мультяшный стиль
- 1920×1080 · 30 FPS · **120 секунд**
- Бип **поёт** названия цифр (русский TTS + мелодический pitch)
- Русские субтитры крупно внизу (+ `.srt`)
- Вся графика сгенерирована индивидуально в Python (Pillow), без Godot и без чужих ассетов

## Сюжет

1. Интро: «Бип считает до десяти»
2. По очереди цифры **1→10**: большая цифра-бейдж + столько же милых предметов
3. Бип «поёт» слово числа
4. Финал: все цифры радугой, «Ура! От одного до десяти!»

| Цифра | Слово | Предметы |
|------:|-------|----------|
| 1 | Один | звезда |
| 2 | Два | сердечки |
| 3 | Три | шарики |
| 4 | Четыре | цветы |
| 5 | Пять | рыбки |
| 6 | Шесть | яблоки |
| 7 | Семь | бабочки |
| 8 | Восемь | конфеты |
| 9 | Девять | уточки |
| 10 | Десять | кубики |

## Индивидуальные ассеты

Все файлы в `ep003_2d/assets/`: небо, холмы, солнце, облако, Бип (позы), бейджи 1–10, предметы счёта, баннер.

```bash
./scripts/build_ep003_2d.sh
```
